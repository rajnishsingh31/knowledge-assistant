# Retrieval-Augmented Generation

Retrieval-Augmented Generation combines information retrieval with an LLM.

The retriever finds relevant document chunks before the model generates an answer.

Vector search is useful for semantic similarity.

BM25 is useful for exact terms, identifiers, error codes, and API names.

Hybrid retrieval combines keyword and vector search.

A reranker evaluates retrieved candidates more deeply.

Citations allow users to trace answers back to source documents
