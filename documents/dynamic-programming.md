# Dynamic Programming (DP) concepts:

## Overlapping subproblems: 
Re-evaluating the exact same sub-calculations multiple times throughout execution.

## Memoization: 
Top-down approach that caches function call results to avoid redundant calculations.

## Tabulation: 
Bottom-up approach that iteratively fills a table (array/matrix) starting from base cases.

## House Robber: 
Classic DP problem maximizing non-adjacent element selection using state decisions.

## State transition:
The mathematical formula/rule defining how current subproblem states build on prior states.
