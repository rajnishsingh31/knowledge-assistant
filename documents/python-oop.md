# Python Opps

## Classes: 
Blueprints for creating objects, defining attributes (data) and methods (behavior) using class.

## Objects: 
Instances of a class containing actual values rather than definitions.

## Inheritance: 
Allows a child class to inherit attributes and methods from a parent class (class Child(Parent):).

## Polymorphism:
Ability for different classes to share the same method name while implementing unique behaviors.

## Encapsulation:
Restricting direct access to data by using private/protected attributes (_var or __var) and getters/setters.

## Abstract Base Classes:
Defined via the abc module (ABC, @abstractmethod) to enforce method implementation in subclasses.

## dataclass:
Decorator (@dataclass) that automatically generates boilerplate methods like __init__, __repr__, and __eq__.
