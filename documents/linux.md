# Linux commands

## ls:
Lists files and directories in the current or specified path.

## cd:
Changes the current working directory (cd /path/to/dir).

## pwd:
Prints the full path of the current working directory.

## touch:
Creates a new empty file or updates access timestamps.

## cp:
Copies files or directories from source to destination (cp src dst).

## mv:
Moves or renames files and directories.

## grep:
Searches text for matching patterns within files or command output.

## find:
Searches the directory tree for files matching criteria like name or size.

## chmod: 
Modifies file access permissions (e.g., read, write, execute).

## nano: 
Opens a user-friendly, terminal-based text editor.

## head:
The head command displays the beginning of a file

## tail:
The tail command displays the end of a file.
