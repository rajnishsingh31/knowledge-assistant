## Python Basics

### Variables:
Named references storing data values in memory (x = 10).

### Lists: 
Ordered, mutable collections allowing duplicates ([1, 2, 2]).

### Dictionaries:
Key-value pairs providing fast lookups by unique keys ({"a": 1}).

### Sets:
Unordered collections of unique elements, useful for deduplication ({1, 2}).

### Functions:
Reusable code blocks defined with def that accept inputs and return outputs.

### enumerate:
Adds an automatic counter to an iterable during loops (enumerate(items)).

### Counter:
A dictionary subclass from collections for frequency counting.

### heapq:
Implements min-heap algorithms on standard lists for priority queue operations.
