# BM25 retrieval concepts:

## TF (Term Frequency):
Measures how often a term appears in a document, with diminishing returns to prevent keyword stuffing.

## IDF (Inverse Document Frequency): 
Downweights common words and boosts the relevance score of rare terms across the corpus.

## Rare terms: 
High-IDF keywords that strongly signal topical relevance and drive higher similarity scores.

## Document length normalization:
Adjusts scores based on length, preventing long documents from dominating due to high raw term counts.

## Exact identifiers:
Excels at retrieving unique, non-semantic strings like model numbers, IDs, or hash values.

## Error codes:
Precision matching for exact stack trace tokens and system error strings (ERR_404).

## API names: 
Effectively targets specific code symbols, function signatures, and method identifiers.
